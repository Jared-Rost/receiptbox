# Receipt Scanner App

Mobile app for both Android and iPhone that uses the camera to scan receipts, parses the text from them, and stores in a file system. Requires gen AI API key to use (was tested with gemini, but others work too).

# How to run

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

Development build tested using expo app on iPhone.
